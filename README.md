### ALGO-000050: BPP equals P
- **Subfield:** Pseudorandomness, derandomization, and Boolean analysis
- **Open:** Determine whether every bounded-error randomized polynomial-time algorithm can be replaced by a deterministic polynomial-time algorithm.
- **Status:** Open for decades. Strong circuit-hardness assumptions imply derandomization, but the required unconditional hardness is missing.
- **Type:** theory
- **Why:** Determines whether randomness provides an inherent polynomial-time computational advantage.
- **Key works:** Nisan and Wigderson (1994), *Hardness vs Randomness*; Impagliazzo and Wigderson (1997), *P = BPP if E Requires Exponential Circuits*; Impagliazzo (2003), arXiv:cs/0304040.
- **Related:** Cryptography—pseudorandom generators; probability—explicit substitutes for random constructions.
